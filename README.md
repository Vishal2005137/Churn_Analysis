I recently completed an end-to-end Customer Churn Analysis project using Python, SQL and Machine Learning.

The objective was to understand customer churn from both a business and analytical perspective.

What I worked on:

• Integrated 3 relational datasets covering customers, subscriptions and customer support
• Performed data cleaning and quality checks using Pandas
• Engineered customer age, tenure, revenue and support-related features
• Calculated key business KPIs including churn rate, retention rate, ARPU, revenue loss and CLTV loss
• Performed exploratory data analysis across plans, contracts, locations, complaints, CSAT and support escalations
• Used SQLite and SQL queries for customer and churn analysis
• Built Logistic Regression and Random Forest churn prediction models
• Evaluated models using Accuracy, Precision, Recall, F1 Score and ROC AUC
• Created customer-level churn probabilities and risk segments
• Identified active high-risk customers and quantified revenue and CLTV exposure

One of the important parts of this project was preventing data leakage before building the predictive model.

The project helped me understand how a data analyst can move from raw relational data to actionable customer retention insights.
